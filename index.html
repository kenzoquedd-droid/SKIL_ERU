Skilpedia / definisi

🇮🇩 tiap skill ada penjelasan + contoh · 🇬🇧 each skill includes definition & example
Berikut adalah bahasa pemrograman, tools, dan teknologi yang dikuasai. Setiap kartu memuat penjelasan singkat serta potongan kode atau contoh penggunaan.

HTML

dasar web
HyperText Markup Language — bahasa markup untuk struktur halaman web. Setiap elemen dibangun dengan tag.
<!DOCTYPE html> <html> <head> <title>Contoh</title> </head> <body> <h1>Halo Dunia!</h1> <p>Ini paragraf.</p> </body> </html>

CSS

styling
Cascading Style Sheets — mendesain tampilan elemen HTML: warna, layout, font, animasi.
body { background: #f4f9ff; font-family: 'Inter', sans-serif; } h1 { color: #1d5a8b; text-align: center; }

JavaScript

interaktif
JavaScript (ES6+) — bahasa pemrograman yang membuat halaman web dinamis. Berjalan di browser.
// contoh fungsi sederhana function sapa(nama) { return `Halo, ${nama}!`; } console.log(sapa('Budi')); // event klik btn.addEventListener('click', () => { alert('Tombol ditekan'); });

Python

serbaguna
Python — bahasa tingkat tinggi untuk web (Django/Flask), data science, AI, dan skrip.
# fungsi sederhana def greet(name): return f"Halo, {name}!" print(greet("Andi")) # list comprehension squares = [x**2 for x in range(5)]

PHP

backend
PHP: Hypertext Preprocessor — bahasa server-side untuk membangun website dinamis (Laravel, WordPress).
<?php $nama = "Dunia"; echo "Halo $nama!"; $buah = ["apel", "mangga"]; foreach($buah as $b) { echo $b; } ?>

Visual Studio

IDE
Visual Studio Code / VS — code editor ringan dengan ekstensi, debugging, Git integration.
📁 shortcut populer: Ctrl+Shift+P (Command Palette) Ctrl+` (buka terminal) Ekstensi: Prettier, Live Server, Python

Laragon

local dev
Laragon — environment portable untuk pengembangan web (Nginx/Apache, MySQL, Redis, Node). Isolasi project.
📦 auto virtual host: - Laragon > Menu > Quick app - Buat project Laravel tinggal klik "Create Laravel" - SSL otomatis untuk local

XAMPP

localhost
XAMPP — paket Apache + MySQL + PHP + Perl. Paling populer untuk uji coba web lokal.
📁 letakkan project di: C:\xampp\htdocs\projectmu 🔁 Jalankan Apache & MySQL dari control panel. phpMyAdmin di http://localhost/phpmyadmin

Sublime Text

editor ringan
Sublime Text — editor cepat dengan multiple selection, command palette, dan minimalis.
⚡ multiple cursor: tekan Ctrl (Win) / Cmd (Mac) + klik di banyak tempat. Package Control: install plugin seperti Emmet.

Notepad++

windows native
Notepad++ — editor kode sumber gratis untuk Windows, mendukung banyak bahasa, syntax highlighting.
📄 fitur: tab, find & replace dengan regex, record macro, plugin manager. Enkripsi plugin "NppCrypt" tersedia.

GitHub

version control
GitHub — platform hosting untuk repositori Git, kolaborasi, dan CI/CD.
$ git init $ git add . $ git commit -m "first commit" $ git remote add origin ... $ git push -u origin main

Vercel

deploy
Vercel — platform deployment untuk frontend (Next.js, React, static site). Integrasi dengan Git.
🚀 deploy dari GitHub: 1. Import repo di vercel.com 2. Otomatis build & publish 3. Preview untuk tiap pull request

DeepSeek

AI asisten
DeepSeek — asisten AI canggih untuk coding, riset, dan pemecahan masalah (seperti yang membantu membuat web ini).
🧠 contoh prompt: "Jelaskan konsep OOP di Python dengan contoh kode." DeepSeek akan memberikan penjelasan dan snippet yang akurat.

BloxAI

AI platform
BloxAI — tools AI untuk otomatisasi workflow, analisis data, dan integrasi model.
📊 contoh penggunaan: - Memproses dataset dengan AI - Membuat pipeline machine learning - Integrasi API cerdas
